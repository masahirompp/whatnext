# 昇格済みモジュールの契約

`lib/` にある部品は、サイクル8の cycle-end で使い捨て層から昇格した（[ADR-0021](../adr/0021-promote-leaf-modules-to-lib.md)）。サイクルを跨いで書き直さず、永続層として厳格に維持する。

- 使う側（`src/`）は、このディレクトリの契約の docs を読んで使う。中身のコードは読まない。契約に書いていない振る舞いに頼らない。
- 依存は `src/` → `lib/` の一方向だけである。`lib/` から `src/` を import しない（`src/` を消すとビルドが壊れる）。`lib/` の中では、`lib/tmux` が `lib/input/exec` の `Run` を使うだけである。
- テストは各部品の横（`lib/<部品>/*.test.ts`）に置き、`npm test` で流す。`src/` とテストを消しても残る。
- 振る舞いを変えるときは、先に PRODUCT.md・DESIGN.md とこの契約を直し、テストを足してからコードを直す。契約の側が覆ったら、ADR-0021 を遷移させ、部品を使い捨て層に戻す。

| 部品 | 契約 | 中身 |
|---|---|---|
| 入力 | [input.md](input.md) | 外部コマンドの口、`claude agents --json`、Usage、フックと OTel の受け口、会話記録、補う値、プロセス表 |
| tmux | [tmux.md](tmux.md) | 専用の tmux サーバの設定と操作、claude の画面と作業台のセッション、Ghostty の分割 |
| 段の判定 | [tier.md](tier.md) | `--json` の行から段を決める、重複を除く |
| 文字の幅と色 | [text.md](text.md) | 表示幅、切り詰め、揃え、色 |

ここに入れなかったもの（サイクル9で書き直す）: 起動元の導き方（`spawners`）、場所の問い合わせ（`git` と `gh`。#246 が未決）、attach している間のキーの表、段と並び、画面の組み立て、操作、状態のファイル、cli。
